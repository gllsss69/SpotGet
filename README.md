# SpotGet

SpotGet turns Spotify links into useful track and collection details, then helps you download matching audio as MP3. It supports individual tracks, albums, and playlists, with an interface in English and Ukrainian.

## What you can do

- View track title, artist, album, duration, and cover art.
- Browse tracks in an album or playlist.
- Download a single track as an MP3 with embedded metadata and cover art.
- Download an album or playlist as a ZIP archive, with progress shown while tracks are processed.
- See which tracks could not be included in a collection archive.

## How it works

1. Paste a Spotify link for a track, album, or playlist.
2. SpotGet retrieves the available public metadata for that link.
3. For MP3 downloads, SpotGet searches YouTube separately for a matching audio recording.
4. Download the MP3 or, for a collection, receive the processed tracks in a ZIP archive.

Spotify metadata and audio matching are separate steps. A YouTube result may not be an exact match, and some recordings may not be available. If a collection is incomplete, the ZIP includes a report listing tracks that could not be downloaded.
